# Django Labs

Laboratory works for object-oriented programming and Django.

## Lab 1

`lab1_oop.py` contains a parent class `Humanity` and a child class `Nation`.
The example demonstrates inheritance, encapsulation, and polymorphism.

## Lab 2

The repository contains a new Django project generated with `django-admin startproject`.

Run the project:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py runserver
```
